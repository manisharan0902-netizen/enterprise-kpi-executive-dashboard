# Enterprise KPI & Executive Reporting Dashboard
**Repository:** `enterprise-kpi-executive-dashboard`

A BI portfolio project designed for Data Analyst, BI Analyst and Power BI Developer roles.

## Business problem
Executives need one governed view of business-unit performance, target attainment, revenue, profit, variance and data quality.

## Deliverables
- SQL KPI layer
- Power BI-ready dataset
- DAX measure examples
- Python validation/summary analysis
- Executive dashboard blueprint

## Suggested dashboard pages
1. Executive Overview
2. Business Unit Performance
3. Variance & Trend Analysis
4. Data Quality

## Skills demonstrated
Power BI, DAX, Power Query concepts, SQL, KPI definition, data visualization, executive reporting, validation.

**Data:** Synthetic public portfolio data; no employer/confidential data.
