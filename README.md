# Executive Sales & Revenue BI

## Business Problem
Leadership needs one trusted view of revenue, profit, regional performance, product mix, and target attainment.

## What This Project Demonstrates
- KPI definition and executive reporting
- SQL aggregation and variance analysis
- Power BI / Tableau-ready data modeling
- Trend, region, and product performance analysis
- Business recommendations based on underperformance and margin

## Dataset
Synthetic portfolio dataset created for demonstration. It does not contain employer or confidential data.

## Key KPIs
Revenue, Profit, Margin %, Units, Target Attainment %, Regional Contribution

## Tools
SQL, Python, Power BI/Tableau, Excel

## Run
```bash
pip install pandas
python analysis/sales_analysis.py
```
